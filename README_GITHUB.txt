JULIO APICELO | TRAINING OS 4.0

PUBLICAR NO GITHUB PAGES
1. Crie um repositorio PUBLICO, por exemplo julio-training-os.
2. Extraia este ZIP. Faça upload de TODOS os arquivos para a RAIZ do repositorio (incluindo index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png e .nojekyll).
3. Settings > Pages > Build and deployment > Deploy from a branch.
4. Selecione main e /(root); Save.
5. Abra https://SEUUSUARIO.github.io/julio-training-os/ no Safari.
6. Compartilhar > Adicionar à Tela de Inicio.

OBSERVACOES
A publicacao do codigo no GitHub Pages e publica. Seus registros sao guardados no navegador do aparelho (localStorage), nao no GitHub. Eles nao sincronizam entre dispositivos e podem ser perdidos se os dados do Safari forem apagados. Exporte backups periodicamente.
