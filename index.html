DIAGNÓSTICO

Como usar no iPhone

Esta versão tem dois modos:

Modo visualização: os dias, exercícios e checkboxes funcionam sem JavaScript. As marcações não ficam armazenadas após fechar o arquivo.

Modo interativo: ao abrir a página em um navegador com JavaScript e armazenamento liberados, o aplicativo registra cargas, repetições, séries e sessões no próprio dispositivo.

Para obter histórico confiável no iPhone: publique o arquivo index.html em uma hospedagem HTTPS (como GitHub Pages ou Netlify), abra o endereço no Safari e use “Adicionar à Tela de Início”.

Backup: o armazenamento do navegador é local e pode ser apagado. Exporte os dados regularmente.

Backups e dados

Observação: se você vir “Modo visualização” no topo, o aplicativo não está gravando as marcações. Não dependa desse modo como histórico permanente.
